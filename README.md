# Network Security Log Analysis

## Project Overview

This project analyzes authentication logs to identify suspicious login activity and potential security threats.

## Objectives

- Identify failed login attempts
- Detect suspicious IP addresses
- Analyze authentication activity
- Practice basic cybersecurity log analysis

## Tools & Technologies

- Python
- Linux
- Authentication Logs
- GitHub

## Analysis

The project will analyze sample authentication logs and identify unusual login patterns that may indicate a potential security incident.

## Results

The analysis will identify suspicious login attempts and provide basic security recommendations.
